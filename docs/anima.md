# Anima gallery presets

The presets use native Anima loading and text conditioning. `SEAnimaGalleryPrompt` resolves seeded choices from the existing reference gallery; the normal advanced encoder handles weights and schedules. `SEAnimaGalleryGuider` selects plain CFG or the built-in reference adapter, adapted from ElectronGirl's ComfyUI-Anima-Ref-Adapter (Apache-2.0, `docs/AnimaRefAdapter-LICENSE.txt`): the reference is a clean second latent frame at timestep 0 whose RoPE rows start one target height lower, the adapter LoRA is hooked only during that reference forward call, and text and reference guidance are separate terms with APG or CFG-rescale correction. No separate node pack is needed; with the same reference, prompt and seed it reproduces the original nodes' output pixel for pixel. Ordinary Easy Use LoRAs apply before it. `SEAnimaNoise` delegates noise and variation seeds to the existing Swarm sampler noise implementation.

Use Anima base v1.0, Qwen3 600M under Swarm's `qwen_3_600m.safetensors` filename and the shared Qwen-Image VAE. The core bundle prefers native INT8 ConvRot and keeps BF16 as an individual catalog alternative. Arithmetic is BF16 because Anima overflows in fp16. The adapter is loaded only on the reference path; use the first gallery image and describe the new pose, scene and framing.

Both presets sample at about 1 MP (1024x1024 by default), decode, scale pixels 2x with Lanczos, re-encode and run 12 ordinary Anima detail steps at denoise 0.3, with the reference adapter off. That produces a 2048x2048 final image. Anima is made for 512x512 to 1536x1536: direct 2048x2048 text to image drew malformed arms and a malformed falcon in our A/B (2 prompts, 2 seeds) where the two-pass recipe stayed clean, and it was about 10% slower. Direct 4 MP reference sampling showed grid artifacts in the author's native graph with both BF16 and INT8. Latent-space enlargement softened the line work; pixel-space refinement retained clean lines.

The presets combine the model card's recommended prefix and negative with the adapter's showcase prompt: the prefix `masterpiece, best quality, score_7, newest, highres, absurdres, safe,` and the negative `nsfw, worst quality, low quality, score_1, score_2, score_3, artist name, signature, watermark, blurry, jpeg artifacts, chromatic aberration, bad anatomy, bad hands, extra fingers`.

The gallery retains added prompts and .txt folder batches. Batch-size references repeat the same character latent; native guidance remains separate for positive, negative and reference-free branches. Fine accessories and strong painterly styles can drift. The reference adapter supports one character/style image; extra gallery cards do not supply separate character and style references.
